# 中文界面文案修复设计

## 目标

统一 KY-DIMM 当前实现中所有可能显示给用户的中文文案，修复术语、标点、单位、状态表达和错误提示不一致的问题；同时整理历史遗留界面标题和项目说明文档。此次修改只调整显示文本和文档表述，不改变测量算法、配置含义、文件格式、信号名称或控件对象名。

## 范围

纳入本次修改的文件和内容：

- `src/MainWindow.cpp`：主界面标签、按钮、状态文本、日志、弹窗、运行时错误前缀。
- `src/SettingsDialog.ui`：设置页标题、字段标签、帮助说明、复选框、占位文本和浏览按钮。
- `src/SettingsDialog.cpp`：触发模式名称、动态分组标题、目录选择器标题、应用按钮和参数错误弹窗。
- `src/AppConfig.cpp`、`src/CameraWorker.cpp`、`src/CentroidEngine.cpp`、`src/MeasurementWorker.cpp`、`src/PylonCamera.cpp`、`src/ResultWriter.cpp`、`src/TwoStarTracker.cpp`、`src/AtmosphereCalculator.cpp`：会通过 UI 日志、状态卡片或弹窗呈现的错误、诊断和计算状态文本。
- `src/UI_New.ui`：历史遗留窗口的可见窗口标题；不增加或恢复其空白布局，也不把它接入主程序。
- `KY-DIMM-项目介绍.md`：保持 UTF-8 编码，整理中文措辞、标点、空格、单位和链接文字；不把终端误显示的乱码重新写入文件。

不纳入本次修改的内容：

- 算法、线程、相机控制、配置校验规则和数据输出格式。
- 控件 `objectName`、C++ 类名、信号槽名、枚举值、CSV/JSON 字段名和文件名。
- 代码注释中的纯技术说明，除非它与修改后的用户可见文本直接矛盾。
- `docs/superpowers/plans` 中的历史执行计划；它们保留为历史记录。

## 文案规范

### 术语

- 统一使用“跟踪”，不使用“追踪”。
- 使用“相机”“采集”“测量”“定位”“重定位”“质心”“连通域”等项目已有技术术语。
- `ROI`、`AOI`、`Mono8`、`Otsu`、`StarA`、`StarB`、`r0`、`seeing`、`theta0`、`tau0`、`Line1` 等技术标识保持原样。
- `ROI`、`AOI` 与中文之间保留一个空格，例如“ROI 跟踪”“硬件 AOI”。
- “有效帧”只用于相机帧计数；与统计窗口中的有效样本对应时，使用“有效样本”或“有效样本数”。

### 标点与状态

- 状态标签统一使用全角冒号 `：`，格式为“字段：状态”，例如“相机：未连接”“采集状态：已停止”。
- 操作日志使用简短、完整的动作句，不使用不必要的省略号；进行中的状态使用“正在连接”“正在断开”“正在停止”。
- 结束状态使用“已连接”“已断开”“已停止”等完成态，避免“停止”同时表示动作和结果。
- 错误弹窗标题统一采用明确的原因类别，例如“参数无效”“相机能力不满足配置”“无法开始数据记录”。错误正文按“现象 + 原因/处理建议”组织，已有底层错误信息不改变其技术含义。

### 数值、单位与格式

- 数值与单位之间保留一个半角空格：`5.86 µm`、`2500 mm`、`100 Hz`、`1 ms`。
- 尺寸乘号使用 `×`，两侧保留空格：`1920 × 1200`、`64 × 64`。
- 坐标使用半角逗号和紧凑格式：`(x, y)`；AOI 坐标显示为 `AOI：宽 × 高，位置 (x, y)`。
- 物理量符号与数值之间保留空格：`D = 60 mm`、`B = 150 mm`、`f = 2500 mm`、`λ = 550 nm`。
- 文件名、参数名和 SDK 节点名不翻译、不插入中文标点。

## 具体文案方向

### 主界面

- “相机: 未连接”统一为“相机：未连接”；相机型号和序列号使用“相机：型号 / 序列号”。
- “采集状态: 停止”统一为“采集状态：已停止”；“正在停止...”统一为“采集状态：正在停止”。
- “实际测量率: …”统一为“实际测量率：…”。
- 按钮统一为“连接相机”“断开相机”“设置”“开始采集”“停止采集”。
- 预览占位统一为“全画幅 1920 × 1200”“ROI A 64 × 64”“ROI B 64 × 64”。
- ROI 状态统一为“StarA：未定位”“StarB：未定位”“ROI 跟踪：未开始/定位中/跟踪中”。
- 统计项区分为“相机丢帧”“队列丢帧”“有效样本：当前值 / 窗口值”。
- “最后错误：-”保留为无错误占位，但所有前缀统一使用全角冒号。

### 设置窗口

- 设置页和分组标题采用简洁、平行的名词短语：物理/光学参数、采集参数、图像处理参数、触发设置、数据存储；动态分组统一为“ROI 与 AOI”“Otsu 与质心”“ROI 重定位”“大气参数计算”。
- 所有字段单位采用“标签（单位）”形式，标签与单位之间不添加多余空格；说明文字中的数值和单位遵守统一空格规则。
- “重定中心”统一为“重定位”；“结果更新间隔”保留含义，但说明文字改为自然中文。
- 将“目标样本数”“目标时长”“记录间隔”等字段说明写成可直接理解的操作语言。
- 触发说明明确区分连续采集、软件触发和硬件触发，并将“每帧下发一次触发”改为“每帧发送一次触发信号”。
- “浏览...”统一为“浏览…”，应用按钮保留为“应用”，系统 OK/Cancel 按钮使用 Qt 标准中文文本或项目统一中文文本。

### 运行时错误与诊断

- 统一错误消息中的冒号、单位、空格和句式；例如“请先连接相机，再开始采集”“相机未打开”“未找到任何相机设备”“无法写入 run_metadata.json”。
- 计算状态使用“等待足够的有效样本（当前值 / 目标值）”“差分方差为零，无法计算 r0”“有效”等短句。
- 跟踪诊断使用“全画幅未找到候选目标”“未找到满足最小间距要求的双星对”“软件 ROI 超出当前 AOI”“有效双星”等一致表达。
- 仅修正文案，不改变诊断字符串被写入 CSV/JSON 的字段结构；如果运行元数据会保存这些状态文本，文本内容同步采用新规范。

### 历史界面与项目文档

- `UI_New.ui` 的窗口标题从占位名称改为 `KY-DIMM`，保持其空白历史布局，不新增功能。
- 项目说明文档全部按 UTF-8 保存；修正标题、句式、标点、单位和 Markdown 链接文本，统一使用“窗口中心距离”“有效样本”“重定位”“ROI 跟踪”等术语。
- 文档中的历史事实、硬件参数、测试结果和未完成的硬件验证状态不改写为新的事实；只改善表达和格式。
